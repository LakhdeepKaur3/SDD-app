# Implementation Plan: Full-Stack Todo App

**Branch**: `001-fullstack-todo-app` | **Date**: 2026-09-01 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/001-fullstack-todo-app/spec.md`

## Summary

Build a single-page to-do web application where users can create, view, toggle completion on, and delete tasks. All todo state is persisted in a PostgreSQL database accessed exclusively through a REST API backend. The frontend renders a live task list ordered newest-first, with loading and error states for every API call.

## Technical Context

**Language/Version**: TypeScript (frontend: Node 20 / Next.js 14; backend: Node 20 / Express 4)

**Primary Dependencies**:
- Frontend: Next.js 14 (App Router), React 18, Tailwind CSS
- Backend: Express 4, Prisma 5, PostgreSQL 15

**Storage**: PostgreSQL 15 (via Docker), accessed through Prisma ORM

**Testing**: Manual validation via quickstart guide; no automated test suite in scope for this feature

**Target Platform**: Web browser (desktop-first), served from localhost in development

**Project Type**: Web application (separate frontend + backend)

**Performance Goals**: Task list renders in under 2 seconds; API responses under 500 ms under normal load

**Constraints**: No localStorage for todos; no Next.js API routes; no direct database access from frontend

**Scale/Scope**: Single shared todo list; up to ~100 todos in list with no pagination required
